# V4 and V5 source updates

This source update contains 23 verified UTF-8 source files, enumerated with SHA-256 hashes in [SOURCE-SHA256SUMS.txt](SOURCE-SHA256SUMS.txt). The 16 V4 files derive from the shutdown patch `2b4a592695db23d83b1a02d280c86e50f640a93d8a9830a6baa513b8f3c6e059`; the seven V5 files selectively backport the defensive upstream fix `789269293f241bca2098adb96db4a5a7319105d4`. The sets do not overlap. Base CitizenFX revision is `88a413835e9d7f56633f249880a13f42297153a2`. Together they cover the Linux server runtime source changes reviewed through upstream `5c3065c261fb3ba82032fee6803f247198fec221`; they do not constitute a full build of that upstream revision. The pinned base retains the existing LAN resource-mounter behavior.

The public fork branch was checked against the base at each of these paths before staging: the 20 existing Git blobs matched the base and the three new headers did not exist in either tree. Original source headers and applicable upstream license terms remain intact; the No Sale terms in this repository apply only to the separately identified original tooling and do not relicense CitizenFX or third-party code.

From the repository root, verify the staged source with `sha256sum -c compatibility/SOURCE-SHA256SUMS.txt`. The [public build recipe](PUBLIC_BUILD.md) checks out the exact base and applies these 23 files after verifying the pinned manifest, each overlay file and each original base file; it records an inventory and rechecks the resulting sources. No clean public V5 bootstrap is claimed. See [test results](TEST_RESULTS.md) for private runtime evidence and [known issues](KNOWN_ISSUES.md) for remaining work. Private runtime archives have unresolved corresponding-source and notice gaps and are not cleared for public binary distribution.
